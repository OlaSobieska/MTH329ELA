Definition 14.1.6.

A subspace of \(\bbR^{n}\) is a subset \(H\) of \(\bbR^{n}\) that satisfies the following three properties:
  1. \(\bfzero\) is in \(H\text{.}\)
    🔗
    🔗
  2. If \(\bfu\) and \(\bfv\) are in \(H\text{,}\) then so is \(\bfu + \bfv\text{.}\)
    🔗
    🔗
  3. If \(\bfu\) is in \(H\text{,}\) then so is \(r \bfu\) for any real number \(r\text{.}\)

    🔗
