linear equation

an equation that is (or can be rearranged to be) of the form
\begin{equation*} \textit{number} \text{ times } \textit{variable} \text{ plus } \textit{number} \text{ times } \textit{variable} \text{ plus } \dotsb \text{ equals } \textit{number} \end{equation*}
\begin{gather*} \text{\textit{number} times \textit{variable} plus \textit{number} times \textit{variable} plus } \dotsb\\ \text{equals \textit{number}} \end{gather*}
