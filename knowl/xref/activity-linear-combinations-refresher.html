Activity 14.1.1.

Recall or learn that a vector \(\bfv\) is a linear combination of vectors \(\bfv_{1}, \bfv_{2}, \ldots, \bfv_{n}\) if you can write \(\bfv\) as a sum of scalar multiples of \(\bfv_{1},\bfv_{2},\ldots, \bfv_{n}\text{,}\) i.e. if you can find scalars \(c_{1}, \ldots, c_{n}\) so that
\begin{equation*} \bfv = c_{1} \bfv_{1} + c_{2} \bfv_{2} + \cdots + c_{n} \bfv_{n}. \end{equation*}
These \(c_{i}\) are called coefficients, or sometimes weights.
🔗

(a)

Is \(\bfu = \threevec{5}{0}{7}\) a linear combination of \(\bfv_{1}\) and \(\bfv_{2}\text{?}\)

(c)

Can you identify which vectors in \(\bbR^{3}\) can be written as a linear combination of \(\bfv_{1}\) and \(\bfv_{2}\text{?}\) Which vectors cannot be written as a linear combination of \(\bfv_{1}\) and \(\bfv_{2}\text{?}\)
🔗
🔗

(d)

For any vectors that can be written as a linear combination of \(\bfv_{1}\) and \(\bfv_{2}\text{,}\) determine which coefficients need to be used.
